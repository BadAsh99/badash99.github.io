As a PSC, I don't just deploy the product; I need to understand what it's defending against to make architecture recommendations that aren't theoretical.

**What's in here:**
- Cross-application attack chain detection
- Prompt injection identification and classification
- AI red team workflows (AIRS-aligned)
- Multi-service LLM runtime security validation

**Stack:** Python · FastAPI · Docker · AIRS alignment framework
